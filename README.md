## Backend Setup
1. Navigate to the `api` folder: `cd api`.
2. Activate the virtual environment:
   -  `source bin/activate `
3. Install the dependencies: `pip3 install -r requirements.txt`.
4. Initialize the SQLite database: `python3 init.db`.
5. Export Flask app: `export FLASK_APP=app/app`
6. Launch the backend server: `flask run`.

## Frontend Setup
1. Navigate to the `front` folder: `cd front`.
2. Install `http-server` using npm: `npm i http-server`.
3. Start the server: `http-server`.

## Accessing the App
Once the backend and frontend servers are running, you can access the app by opening your web browser and visiting `http://localhost:8080`.
